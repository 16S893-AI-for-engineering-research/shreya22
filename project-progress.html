Progress

Current status of the pipeline and task work. Narrative notes live in the Dev Log; this page tracks the research pipeline itself.

Note on the Methods page: The Methods page still describes an older “spectrum” framing (hub-centricity as a continuous variable). The project has since adopted a binary network comparison (hub-and-spoke vs. point-to-point serving fixed demand) per ADR 0001 — the Methods page will be updated in a later sprint.

Pipeline diagram

The eight stages below are the full analysis pipeline. Status uses both color and a shape cue (not color alone).

Task status

01 · Demand & network baseline

Status: in progress

BTS DB1B adapter is in progress (streaming chunk reader, ×10 sample correction, study-region filter: BOS, DEN, DTW, MSP, ORD, SFO). Network builder (hub-and-spoke + point-to-point), invariant checks, network totals, and CLI are done. See the Prototype page for the 3-airport mock that verifies the builder end-to-end.

02 · Fleet & emissions

Status: in progress

Real aircraft per route from BTS T-100 (passenger-configured flights only; BTS aircraft codes mapped to OpenAP models) is in progress. OpenAP fuel/NOx integration is in progress; current coefficients are placeholder values, not results.

03 · Emissions to impacts

Status: not started

GEOS-Chem adjoint sensitivity application and health-burden calculation (Turner et al. ozone CRF, GEMM PM2.5 concentration-response) not yet started.

04 · Trade-off mapping

Status: not started

Final synthesis and sensitivity tests on every proxy assumption. Depends on stages 1–3 being complete.

Why the home page looks the way it does

The animated flight network and the emissions-trail easter egg on the home page are a direct visual reference to this project: a network of routes, and the invisible cost each one carries.
