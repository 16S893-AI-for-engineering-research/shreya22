# US demand data source: BTS DB1B, not T-100

Status: accepted

Demand data for the US-primary scope (see
`0005-geographic-scope-us-primary-eu-stretch.md`) is BTS **DB1B**
(quarterly 10% ticket sample, itinerary-level, includes connections), not
T-100 (carrier-reported nonstop segment traffic only, no itinerary/
connection information).

DB1B answers the question this project needs &mdash; what passengers'
actual origin-to-destination journeys look like, including which legs are
connections &mdash; which T-100 cannot, since T-100 only reports nonstop
segments with no way to reconstruct a passenger's full itinerary. The
trade-off is that DB1B is a 10% sample (sampling noise, especially on thin
routes) and quarterly rather than continuous, versus T-100's full-census,
monthly nonstop-segment counts.
