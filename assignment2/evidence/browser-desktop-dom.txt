    <h1>Reproducing an airline-network comparison</h1>
    <p class="lede">One published figure, two network structures, and a strict check of the numbers behind the comparison. The result is a reconstruction and source-consistency audit—not yet an independent rerun of the paper’s model.</p>
    <div class="scope-tags">
      <span class="tag">Hub-and-spoke vs. city-to-city</span>
      <span class="tag">Fuel · NOₓ · CO · HC</span>
      <span class="tag">uv + test-driven development</span>
    </div>

    <section class="status-box" aria-labelledby="status-heading">
      <h2 id="status-heading">First pass complete · strict agreement not achieved</h2>
      <p><strong>16/20 published consistency checks pass at 0.1% relative error.</strong> The rendered figure uses Table 7’s base-case values; mismatches with Figure 4 annotations and Section 4.3 are retained below. These checks are not independent physical validation or a confidence score.</p>
      <p>Passing software tests confirms that the code calculates, plots, and flags discrepancies correctly. It does <strong>not</strong> establish that the published model has been reproduced.</p>
    </section>

    <section aria-labelledby="paper-heading">
      <h2 id="paper-heading">The paper and the target</h2>
      <p>Sun, M., Tian, Y., Zhang, Y., Nadeem, M., &amp; Xu, C. (2021). <a href="https://doi.org/10.3390/su13020465">Environmental Impact and External Costs Associated with Hub-and-Spoke Network in Air Transport</a>. <em>Sustainability, 13</em>(2), 465.</p>
      <p><strong>Target: Figure 4, “The total environmental impact of two airline networks.”</strong> It compares total fuel burn and NOₓ, CO, and HC emissions for a ten-airport Chinese case. Only these four original quantities are plotted; no derived CO₂ series has been added.</p>
      <p class="note">This course exercise is separate from the semester project’s US-focused, population-weighted exposure comparison. It does not change those modeling decisions.</p>
    </section>

    <section aria-labelledby="agreement-heading">
      <h2 id="agreement-heading">Does the quantitative comparison agree?</h2>
      <p>For each quantity, the independently recomputed arithmetic is <code>reduction (%) = 100 × (city − hub) / city</code>. The inputs are the published aggregates, not independently simulated fuel/emissions. The reference reduction percentages below are those stated in Section 4.3.</p>
      <div class="table-scroll" role="region" aria-label="Reduction comparisons at 0.1 percent relative tolerance" tabindex="0">
        <table id="reductions-table">

      <p><strong>Percentage points are not relative percent error.</strong> A small percentage-point gap can still fail this strict relative criterion. Three-significant-figure source totals limit attainable precision; rounding could explain the small reduction discrepancies. The tolerance has not been relaxed and no extra significant digits have been invented.</p>
    </section>

    <section aria-labelledby="discrepancy-heading">
      <h2 id="discrepancy-heading">The source disagrees with itself</h2>
      <div class="table-scroll" role="region" aria-label="Disagreements between reported absolute totals" tabindex="0">
        <table id="discrepancies-table">
          <caption>Absolute-total checks that fail, with Table 7 as the named reconstruction source.</caption>
          <thead><tr><th scope="col">Quantity / network</th><th scope="col">Table 7</th><th scope="col">Other source</th><th scope="col">Reference</th><th scope="col">Relative error</th></tr></thead>
          <tbody><tr><th scope="row">HC / city-to-city</th><td>4.14 × 10<sup>8</sup></td><td>4.14 × 10<sup>9</sup></td><td>Figure 4 annotation</td><td>90.000000%</td></tr>
<tr><th scope="row">HC / hub-and-spoke</th><td>1.49 × 10<sup>8</sup></td><td>1.48 × 10<sup>8</sup></td><td>Section 4.3 prose</td><td>0.675676%</td></tr>
</tbody>
        </table>
      </div>
      <ul>
        <li><strong>HC exponent:</strong> Figure 4’s city-to-city annotation says 4.14 × 10<sup>9</sup>; its apparent bar height, Table 7, and Section 4.3 instead support 4.14 × 10<sup>8</sup>. Both printed values are preserved in the input data.</li>
        <li><strong>HC total:</strong> hub HC is 1.49 × 10<sup>8</sup> in the figure/table but 1.48 × 10<sup>8</sup> in the prose. The earlier planning response used the prose value; the original-figure audit caught the discrepancy before implementation.</li>
        <li><strong>Units need investigation:</strong> the printed hub NOₓ and fuel totals imply about 40 kg NOₓ per kg fuel, whereas Table 3 gives emission indices in the tens of <em>grams</em> per kg. This is an order-of-magnitude warning, not a license to silently divide the source data by 1000.</li>
      </ul>
      <p>The qualitative ordering is reproduced from the reported totals. The original annotations, prose, and Table 7 cannot all be matched at 0.1%. This first pass therefore does not validate the paper’s physical emissions estimates or establish a general environmental advantage for hubs.</p>
    </section>

    <section aria-labelledby="skills-heading">
      <h2 id="skills-heading">How the agent was managed</h2>
      <ol>
        <li><strong>Paper-result audit:</strong> verify citation/license, inspect the actual figure and table, preserve conflicting evidence, and set the numerical contract before coding.</li>
        <li><strong>Scientific TDD:</strong> observe failing tests, implement the smallest calculations, then rerun the complete suite. Tests cover independent arithmetic fixtures, zero/invalid baselines, mass-unit round trips, and scale/order invariance—not a claim that hubs must always emit less.</li>
        <li><strong>Reproduction figure:</strong> check actual bar heights and labels, preserve the original variable selection/scale, export deterministically, and inspect the resulting image.</li>
      </ol>
      <p>These project-local skills adapt reviewed community workflows from <a href="https://github.com/obra/superpowers/tree/main/skills/test-driven-development">obra/superpowers</a> and <a href="https://github.com/K-Dense-AI/scientific-agent-skills">K-Dense Scientific Agent Skills</a>. No paid service or generative-image tool was used. <a href="assignment2/SKILLS.md">Skill sources and concrete use</a> · <a href="assignment2/evidence/README.md">Red/green execution evidence</a>.</p>
    </section>

    <section aria-labelledby="next-heading">
      <h2 id="next-heading">What this first pass establishes—and what comes next</h2>
      <p><strong>The computation is intentionally small:</strong> it reconstructs published aggregates and checks arithmetic. This is useful as a reproducibility audit, but it is too limited to claim an independent reproduction of a network/emissions model.</p>
      <p>A stronger second pass would implement a small network and the paper’s phase-by-phase fuel/emissions accounting, with explicit demand, aircraft, and flight-time inputs. The missing original demand matrix, trajectory histories, and licensed BADA performance coefficients must be resolved first. Any reduced or proxy-data version would be labelled an <em>adaptation</em>, not claimed to reproduce Figure 4’s absolute numbers.</p>
